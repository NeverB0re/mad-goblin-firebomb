# Mad Goblin Firebomb (미친 고블린) — 0.2 (본편 50개 진지)

부족장을 납치당한 미친 고블린이, 협박 대신 폭탄으로 대답하며 인간 진지를 하나씩 박살 낸다.
언덕에서 무거운 화염탄·고폭탄·기름탄·조명탄을 높이 띄워 던져 지휘관을 쓰러뜨리면 승리 (전령 스테이지는 전령을 맞히거나 건널 다리를 끊어 멈추기).
화면에 목표 문구는 없다. 재질을 보고 직접 던져 보며 알아낸다: **짚·나무 = 탄다, 금 간 석벽 = 고폭탄으로 부서진다, 반듯한 석재 = 버틴다, 강철 = 절대 안 부서진다.**

Godot 4.7 / GDScript / Jolt Physics / Mobile 렌더러.
기획서: [확장 프로토타입 기획서](화염병%20투척%20게임%20확장%20프로토타입%20기획서.md), [기존 프로토타입 기획서](docs/prototype_plan.md)

## 게임 흐름

타이틀 (뒤에 진지가 멈춘 채 돈다) → 처음이면 오프닝 만화 → 월드마다 시작 만화 → 5개 월드 50개 진지 → 엔딩 만화 → 타이틀.
- **이어서 공격**: 아직 못 깬 첫 진지부터. 깨면 다음 진지가 열리고, 진지마다 최고 기록(남긴 탄 수)을 남긴다.
- **진지 고르기**: 월드 탭을 골라 열린 진지 아무거나. **처음 이야기**: 오프닝 다시 보기. **설정**: 마우스 감도, 소리 크기, 전체 화면.
- 진행과 설정은 `user://save.cfg`에 저장된다 (Windows: `%APPDATA%\Godotpp_userdata\Mad Goblin Firebomb`).
- 게임 중 Esc = 잠깐 메뉴 (계속, 다시 공격, 진지 고르기, 설정, 처음 화면으로).

## 본편: 5개 월드 × 10개 진지 (확장 기획서 11장)

월드 안의 틀: 1~2 새 요소 소개, 3~6 유형 응용, 7 쉬어 가기, 8~9 섞기, 10 클라이맥스. 진지마다 짧은 서사가 있어
구조물이 그 자리에 있는 이유가 말이 된다 (예: 1-5 마을 종탑: 석조 초소 위 나무 종틀에 밧줄로 매단 쇠종). 서사는 `scripts/campaign.gd`의 story 항목.

| 월드 | 새 요소 | 진지 |
| --- | --- | --- |
| 1 점령당한 목책 마을 | 화염탄, 구경하는 마을 고블린 | 마을 어귀 망루, 빼앗긴 대장간, 곡식 창고, 개울 다리의 전령, 마을 종탑, 고블린 화약 창고, 추수 축제 무대, 건초 더미 옆 망루, 두 마구간 사이의 전령, 촌장 집 점령군 본부 |
| 2 철벽 관문 | 고폭탄, 강철(불파괴), 금 간 석벽, 간접형 | 관문 초소, 석재 망대, 석벽 마당 막사, 해자 다리의 전령, 절벽 감시굴, 화약 수레 창고, 허수아비 훈련장, 강철 성벽 뒤 막사, 관문 탑과 화약, 성문 앞 지원 |
| 3 증기 광산 도시 | 기름탄, 비와 젖은 목재, 광차 전령 | 연료 창고, 빗속 광부 숙소, 광차 전령, 비 맞는 감시탑, 보일러 망대, 무너진 갱도 입구, 석탄 적재대, 빗속 광차 전령, 연료관 골목, 정련소 |
| 4 대공 요새 | 조명탄, 밤, 바람(바람자루), 발리스타 | 밤의 진지, 바람 부는 사열대, 발리스타 탑, 횃불 든 전령, 바람 속 화약고, 밤의 감시굴, 보급 막사, 바람 속 석벽 초소, 밤바람 전령, 대공 요새 본루 |
| 5 왕국 성채 | 플레어건과 탄도미사일, 대공 발리스타 | 첫 표적 지정, 나무 발리스타 하나, 석재 발리스타, 성 안 다리의 전령, 두 발리스타, 지하 감옥 입구, 왕실 마구간, 왕성 성문 지원, 바람 속 발리스타, 왕국 성채 본진 |

- **월드 시작 컷:** 월드 첫 진지에 처음 들어갈 때 2칸 만화 (그 월드 지휘관의 으름장 → 고블린들이 새 무기에 불을 붙이며 웃음).
- **컷신:** 오프닝 6칸, 엔딩 3칸, 월드 시작 2칸 모두 2D로 그린 만화 (`scripts/comic_art.gd`, `opening.gd`). 게임 3D 모델을 쓰지 않는다.
- **바람:** 투척체에 일정한 수평 가속. 플레이어 옆 바람자루와 깃발이 방향·세기를 보여 준다.
- **비:** 빗줄기와 흐린 하늘. 비 맞는 목재는 젖은 목재(기름이 필요), 지붕 덮인 다리는 마른 채.
- **광차 전령:** 궤도(레일·침목)를 따라 광차를 타고 달린다. 다리를 끊으면 멈춘다.
- **발리스타:** 하나라도 서 있으면 탄도미사일을 공중에서 쏘아 떨어뜨린다. 나무 탑(불)과 금 간 석재 탑(고폭탄).
- **플레어건과 탄도미사일:** 플레어건으로 맞힌 지점에 1초 뒤 후방 미사일이 날아와 떨어진다. 미사일은 반경 9m 큰 폭발에, 6m 안의 인물은 엄폐와 상관없이 쓰러뜨린다.
- **실패 그림:** 월드마다 배경 색과 소품이 다르다 (강철판, 보일러, 발리스타 받침, 성탑).

## 실행

- `실행.cmd` 더블클릭, 또는 `Godot_v4.7.2-stable_win64.exe --path .`
- 테스트: `powershell -ExecutionPolicy Bypass -File tests\run_tests.ps1`
  - `determinism_test`: 같은 위치·각도 20회 투척 착탄점 동일, 45도 사거리
  - `campaign_test`: 본편 50개 생성, 진지마다 설계상 풀이를 실제로 던져 이기는지 (바람은 감안해 겨눔), 발리스타 요격. 인자로 월드 번호(1~5)를 주면 그 월드만
  - `menu_test`(창 모드): 타이틀 → 시작 → 잠깐/계속 → 클리어 저장 → 진지 고르기 (시험용 저장 파일 사용)
  - `menu_shot.gd`(창 모드): 타이틀·진지 고르기·잠깐 메뉴·새 진지 화면 저장
  - `stage_test`: E1~E11을 실제 와인드업 투척 경로로 풀이, 승리·실패(탄약 소진, 전령 도착) 판정, 순서·엄폐 확인, 재시작 1초 이내, 블록 150개 이하
  - `input_test`(창 모드): 마우스 시점, 와인드업·투척, 우클릭 취소와 줌 규칙, 추적 화면
  - `opening_shot`(창 모드): 오프닝 6컷, 엔딩 2컷
  - `screenshot.gd`(창 모드): 스테이지별 와인드업·결과, 승리 연출, 실패 그림을 `tests/out`에 저장
  - `debug_probe.gd`: 스테이지에 정해 둔 투척을 하고 블록·지휘관 상태를 출력 (설계 조정용)

## 기획서와 다르게 정했거나 아직 못 한 점

- **무거운 폭탄 (플레이 피드백):** 화염탄 23m/s(예전 고폭탄의 약 90%), 고폭탄 20.5, 기름탄 22, 조명탄 27. 평지 45도 사거리는 화염탄 54m, 고폭탄 43m라 더 위를 겨눠 던져야 한다. 투척 구역을 스테이지마다 진지 쪽으로 당겨 표적이 사거리 3/4 안팎에 오게 했다.
- **전령 멈추기 (플레이 피드백):** 봉화대는 뺐다. 전령을 맞히거나, 건너야 할 개울 위 나무다리를 끊으면 전령이 다리 앞에서 오도 가도 못해 승리. 목적지는 부서지지 않는 나팔탑.
- **창문과 현실적 시설 (플레이 피드백):** 벽으로 시야를 다 가리지 않고 창문을 내서 표적이 보이게 했다 (E4 초소, E5 마당 벽·막사, E7 창고, E10 마구간). 목책은 가운데 문이 열려 있다. 창으로 폭탄을 넣기는 어렵게 작게 냈다.
- **잔해 충돌층:** 떨어진 잔해는 인물을 밀지 않는다 (지휘관이 날아든 벽 조각에 밀려 막사 밖으로 나가던 문제). 깔림 판정은 따로 본다.

- **글씨 없는 목표 (플레이 피드백):** 목표·힌트 문구와 "무게가 달라졌다" 알림을 없앴다. 화면에는 스테이지 번호와 탄약만 남고, 조작 안내는 첫 투척 뒤 사라진다. 무엇을 해야 할지는 재질로 보여 준다 (위 굵은 글씨).
- **재질 규칙:** 강철은 어떤 폭발로도 끊기지 않는다 (가림막). 반듯한 석재는 고폭탄(최대 320)으로는 안 끊기고 화약통·동료의 폭발통만 통한다. 고폭탄으로 부술 벽은 모두 금 간 석벽(누런 석재 + 검은 균열)으로 바꿨다 (E4, E5, E6 기둥, E10 봉화대 앞, E11 울타리).
- **근처 충격 (플레이 피드백):** 충격은 반경 안에서 거리에 따라 약해지며 연결을 끊고, 끊기지 않은 나무·금 간 석벽은 반경의 1.6배 거리까지 금이 커져(어두워지고 부스러기가 튐) 다음 충격에 쉽게 부서진다. 한 발로 끊기는 범위는 반경 그대로라 예측할 수 있다.
- **낮은 언덕 (플레이 피드백):** 기본 투척 구역은 높이 6m 언덕. 아주 먼 E9만 22m 고지대, 먼 E10은 12m. 지붕 밑을 노릴 때는 높이 띄워 가파르게 떨어뜨려야 한다.
- **궤적 감상 (플레이 피드백):** 비행 시계를 0.8 → 0.64배로 늦췄다 (착탄점은 그대로). 우상단 추적 화면은 손을 떠나는 순간부터 뜬다. 우클릭 줌은 4배.
- **조명탄·밤 승리:** 조명탄은 16초 동안 밝다가 마지막에 빠르게 꺼진다. 밤 스테이지 승리 연출은 연출 카메라에 조명을 달아 보이게 한다.

- **한 발로 끝나는 스테이지:** E2(망루 다리에 불), E3·E10(다리를 한 발에 끊음)은 한 발로 풀린다. 플레이해 보고 판단이 필요하다.
- **승리 연출 (플레이 피드백으로 변경):** 쓰러진 방식에 따라 다르게 찍는다. 날아감(직격·폭발)은 0.45배속으로 1.5초 감상한 뒤 공중 확대샷, 불탐은 정면에서 허둥대는 모습, 깔림·추락은 옆에서 줌을 당겨 잔해와 삐져나온 몸, 봉화대는 타는 봉화대. 그 뒤 멈추고 박살!. 관절 래그돌 대신 몸 전체 회전과 팔 휘두르기로 흉내 냈다.
- **전령 스테이지 (플레이 피드백으로 변경):** 지휘관 없이 "전령 멈추기"가 목표. 경로는 구불구불한 꺾은선이고 뒤 스테이지일수록 빠르고 많이 꺾인다 (E3 2.6m/s, E10 3.4m/s).
- **비계 제거 (플레이 피드백):** 높이 선택은 뺐다. E9는 원거리 스테이지로 남겨, 이 정도 거리를 뒤 스테이지의 난이도 요소로 쓴다.
- **불·폭발의 가림:** 블록이 가리면 불웅덩이와 폭발이 인물에게 닿지 않는다 (E11 초소 안 지휘관).
- **고폭탄 산산조각:** 충격에 직접 끊긴 3.5m³ 이하 석재·금 간 석재 블록은 밀려나지 않고 그 자리에서 부서진다. 밀려난 기둥이 덮개 밑에 끼어 버티던 문제 때문이다.
- **깔림 판정:** 위에서 떨어지는 블록만 친다. 옆으로 튕겨 나가는 과장된 파편은 판정에 쓰지 않는다 (과장은 판정 뒤에).
- **불의 가림:** 불웅덩이와 블록 사이를 다른 블록이 가리면 불이 닿지 않는다 (석재 벽 안의 배관은 바깥 불에 직접 붙지 않음).
- **광원:** 불웅덩이·착탄 섬광의 실제 광원을 없애고 조명탄 하나만 광원을 쓴다. 횃불은 발광 재질과 원뿔 메시.
- **월드 시작 컷:** 오프닝 6컷 안에 "지휘관의 으름장"과 "웃으며 불을 붙이는 고블린"을 넣었다. 월드별 시작 컷은 월드가 하나라 따로 두지 않았다.
- **아직 없음:** 여러 부재가 한 번에 끊어질 때 슬로모션 연장, 공유 재료 8개 이하(지금은 블록마다 재료가 있어 연소 색 변화에 씀), 오브젝트 풀, Windows 실행 파일 내보내기.
- **한 발 풀이:** 기획서는 "한 발로 끝나는 스테이지는 만들지 않는다"지만, 본편 50개 중 상당수(망루, 종탑, 화약고, 다리 전령 등)가 설계상 한 발로 풀린다. 탄 여유와 함께 플레이 후 조정이 필요하다.
- **높이 선택(망루 2층):** 플레이 피드백으로 뺐고, 원거리 진지(요새·정련소·본루)는 높은 언덕으로 대신했다.
- **이전 이야기 교체:** "기계장치의 신 부품" 목표와 오프닝은 확장 기획서의 "부족장 납치·지휘관" 이야기로 바꿨다.
