# 그래픽 참고 자료 (나중 작업용)

지금은 적용하지 않는다. **그래픽 목업을 완성 그래픽으로 업그레이드할 때** 이 자료로 캐릭터를 다시 만들어 교체한다.

## characters_concept.webp: 사용자 구상 캐릭터 5종 (2026-10-05)

현재 게임의 로우폴리 느낌(면마다 평평한 음영, 따뜻한 색)에 맞춰 다시 만들어 교체한다. 머리가 크고 몸이 짧은 귀여운 비율, 각진 면.

| 캐릭터 | 게임 속 역할 | 그림의 특징 |
| --- | --- | --- |
| 지휘관 | 진지의 표적 (Commander) | 검은 판금 갑옷에 금 테두리, 빨간 깃털 장식 투구(눈 가리개), 빨간 망토와 목도리, 빨간 앞치마 천, 장검 |
| 검방병사 | 방패병 (Guard, shield) | 은색 투구, 파란 목도리와 파란 천 옷, 은색 흉갑·어깨·무릎 갑옷, 파란 연 모양 방패(은 테두리, 마름모 무늬), 장검 |
| 창병사 | 창 든 병사 (Guard) | 검방병사와 같은 차림에 방패 없이 긴 창 |
| 궁병 | 망루를 지키는 병사 (새로 추가: 망루 위 감시병) | 초록 두건과 망토, 갈색 가죽 조끼·장화, 등에 화살통, 긴 활 |
| 고블린 | 플레이어와 동료 고블린 (Models.goblin) | 초록 피부, 긴 귀, 노란 눈과 이빨, 빨간 머리털에 이마의 고글, 가슴 가죽 끈과 빨간 병 주머니들, 갈색 반바지·장화, 한 손에 불붙은 심지의 까만 폭탄 |

교체할 곳: `scripts/models.gd`의 `commander()`, `human()`(병사), `goblin()`, 그리고 궁병은 새로 (망루 위에 세운다).
